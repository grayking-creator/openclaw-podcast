[07:05] GitHub Copilot अब अपने कमांड्स को आपकी मशीन पर सैंडबॉक्स करता है

GitHub Copilot अब अपने कंप्यूटर पर चलाई जाने वाली कमांड्स को एक लोकल सैंडबॉक्स में रैप कर सकता है। यह फीचर 7 अक्टूबर से Copilot CLI, Copilot ऐप, और VS Code सेशन में Agent Host का उपयोग करते हुए आम तौर पर उपलब्ध है।

मुद्दा यह है कि एक स्वायत्त एजेंट को आपकी मशीन पर कार्य करने की अनुमति देना है, बिना इसे आपकी तरह कार्य करने की अनुमति दिए। जब Copilot एक टूल कॉल फायर करता है, तो यह अब आपके या आपकी कंपनी द्वारा परिभाषित पॉलिसी के तहत चलता है, और वह पॉलिसी कॉल को अधिकांश फाइलसिस्टम, खुले इंटरनेट, आपके लोकल नेटवर्क, Git क्रेडेंशियल्स, और GitHub CLI क्रेडेंशियल्स से दूर रख सकती है। यदि एजेंट कुछ करने की कोशिश करता है जो पॉलिसी मना करती है, तो यह बस नहीं होता।

अंदरूनी तौर पर, एन्फोर्समेंट Microsoft eXecution Container, या MXC द्वारा संभाली जाती है, जो एक पॉलिसी फाइल को Windows, macOS, और Linux पर नेटिव ऑपरेटिंग-सिस्टम कंट्रोल में अनुवादित करती है। प्रत्येक प्लेटफॉर्म पर सैंडबॉक्स प्रिमिटिव्स अलग दिखते हैं, इसलिए एक सामान्य पॉलिसी का मतलब है कि डेवलपर्स और सिक्योरिटी टीमों को केवल एक बार नियम लिखने होते हैं। वही पॉलिसी लोकल टूल्स को कवर करती है जिन्हें Copilot प्लग इन करता है, जिसमें लोकल MCP सर्वर और लैंग्वेज सर्वर शामिल हैं जहां वे इंटीग्रेशन समर्थित हैं, इसलिए बाउंड्री केवल एजेंट तक सीमित नहीं है। टूल आइसोलेशन को मॉडल चॉइस से जानबूझकर अलग रखा गया है, इसलिए नियम चाहे जो भी मॉडल Copilot उपयोग कर रहा हो काम करते हैं।

बिल्डर्स के लिए, व्यावहारिक अपसाइड यह है कि अपने लैपटॉप को सौंपे बिना एक रियल प्रोजेक्ट पर एजेंट को अधिक जिम्मेदारी देने की अनुमति है। आप परिभाषित करते हैं कि यह कौन से डायरेक्टरीज पढ़ और लिख सकता है, कौन से होस्ट्स इसे कॉल करने की अनुमति है, और कौन से क्रेडेंशियल्स यह देख सकता है। एंटरप्राइज एडमिन इसे आगे ले जा सकते हैं और मैनेज्ड सेटिंग्स के माध्यम से सैंडबॉक्स की आवश्यकता ले सकते हैं, जिसमें पॉलिसीज शामिल हैं जिन्हें डेवलपर्स कमजोर नहीं कर सकते। GitHub इस फीचर को Copilot के साथ बिना किसी अतिरिक्त लागत के शामिल कर रहा है।
