[02:00] DeepSeek Harness v0.2 fügt offizielle Desktop-Apps für macOS und Windows hinzu

DeepSeek hat offizielle Desktop-Apps für sein Open-Source-Agent-Harness, DeepSeek Harness v0.2, veröffentlicht. Die neuen macOS- und Windows-Builds ergänzen die bestehende Web-UI, die über Code mit npx gestartet wird, sodass dasselbe Projekt jetzt ein natives Fenster für alltägliche Benutzer und einen Node-basierten Pfad für Entwickler bietet. Das Harness basiert auf Cordis' „Everything is a Plugin"-Architektur, auf die sich DeepSeek stark verlässt: Tools, Fähigkeiten und sogar UI-Oberflächen werden alle auf dieselbe Weise installiert. Die Vorschau fügt einen Plugin-Manager, Datei- und Code-Änderungsprüfung sowie geplante Automatisierungsaufgaben hinzu, die wiederkehrende Arbeit in einem Kalender ausführen können. In der Demo lässt das Harness einen schwebenden Pomodoro-Timer erstellen, wobei es ein dsh-plugin-pomodoro-float Verzeichnis schreibt, das eine package.json plus eine 638-zeilige client.js für ein rahmenweites Overlay enthält, und es dann innerhalb derselben Sitzung installiert und verifiziert.

Eine zweite bedeutende Änderung ist die Modellflexibilität. Harness v0.2 unterstützt Nicht-DeepSeek-Modelle über OpenAI-kompatible Endpunkte, sodass dieselbe Agentenschleife auf andere Anbieter zeigen kann, ohne das Harness neu aufzubauen. Der Creator-Modus geht noch einen Schritt weiter, indem er Benutzern ermöglicht, ein Plugin im Chat zu beschreiben und das Harness es erstellen, bearbeiten und verifizieren zu lassen, wobei Diffs für jede Datei und Code-Änderung angezeigt werden.

Für das Debugging zeigt die App Ausführungsspuren mit Timing pro Runde, Tool-Aufrufen und einer Hierarchieansicht des Runtime-Kontexts, was nützlich ist, wenn ein mehrstufiger Agentenlauf schiefgeht. Das Projekt ist MIT-lizenziert, noch als Vorschau gekennzeichnet mit sich entwickelnden Kern-Plugins und APIs, und gewinnt auf Hacker News an Popularität, wo der Diskussionsfaden einen Score von 407 erreicht hatte.

[02:54] OpenAIs GPT-6 Astra Ultrafast erreicht 8x schnellere Tokens auf NVIDIA Blackwell

OpenAI hat den Geschwindigkeitsregler bei seinem GPT-6 Astra-Modell ordentlich aufgedreht. Der neue Ultrafast-Modus, der auf NVIDIA Blackwell GPUs läuft, ist jetzt live in der OpenAI API und für berechtigte ChatGPT Work- und Codex-Benutzer. Die Kernzahl: bis zu 8x schnellere Token-Generierung im Vergleich zu Astra Standard.

Diese Lücke ist am wichtigsten in den Schleifen, in denen Agenten tatsächlich arbeiten. Ein Coding-Agent schreibt einen Code-Schnipsel, ruft ein Tool auf, überprüft das Ergebnis und entscheidet, was als nächstes kommt. Jede dieser Hin- und Rückfahrten wartet auf Tokens. Ultrafast verkürzt dieses Warten, was OpenAI als den Unterschied zwischen einem schnelleren Benchmark und einem nützlicheren Produkt positioniert, insbesondere für zeitkritische agentische Workflows.

Die Beschleunigung ist kein handoptimierter Kernel, der von einem kleinen Team entwickelt wurde. OpenAI nutzt seine eigenen Modelle, um die Inferenzsoftware zu verfeinern, die auf NVIDIA-Hardware läuft, und setzt auf die Programmierbarkeit der Blackwell-Plattform, um Verbesserungen zu testen und einzuführen. Philippe Tillet, OpenAIs Inferenzleiter, schreibt NVIDIAs Tools und Dokumentation zu, dass das Team hochleistungsfähige, für Blackwell optimierte Kerne entwickeln konnte. Uday Ruddarraju, OpenAIs CTO für Computing, sagt, dass dieselbe Zusammenarbeit die Geschwindigkeitssteigerung hinter Ultrafast hervorgebracht hat.

Ein praktischer Aspekt für Entwickler: kürzere Edit-Test-Debug-Zyklen und flottere Tool-Aufrufe. Wenn Sie jemals einen Coding-Agent stottern gefühlt haben, während er zwischen Schritten wartet, ist dies die Art von Veränderung, die Sie in einer Sitzung tatsächlich spüren können. Für Teams, die interaktive Apps ausliefern, reduziert dieselbe Geschwindigkeitssteigerung die Latenz, die Benutzer bemerken, wenn ein Modell gerade nachdenkt.

Entwickler können über die API heute auf GPT-6 Astra Ultrafast zugreifen, wobei der Ultrafast-Leitfaden Zugang, Preise und Implementierung abdeckt. Eine Sache zu beachten: OpenAIs Hinweis, dass die Leistungsarbeit nach der Bereitstellung fortgesetzt wird, wobei eigene Modelle verwendet werden, um den Inferenz-Stack auf NVIDIA GPUs weiter zu optimieren.
