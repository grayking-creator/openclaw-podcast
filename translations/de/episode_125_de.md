[NOVA]: BeNice ist eine Post-Training-Methode für Modelle, die Informationen wiederholt durch dieselben Schichten leiten. Gemeinsame Caches machen diesen Tausch für den Speicher weniger kostspielig. [NOVA]: Cognition hat als Reaktion auf kritische Schwachstellen bei der Remote Code Execution, die PHP-, Node.js- und selbst verwaltete GitLab-Deployments betreffen, das Devin Vulnerability Fixes Plugin als Open Source veröffentlicht. Ein Unternehmen mit Dutzenden Services kann mehrere betroffene Abhängigkeitspfade, unterschiedliche Build-Systeme und verschiedene Verantwortliche haben; die Vorbereitung einer isolierten Änderung pro Repository gibt diesen Verantwortlichen etwas Konkretes zur Prüfung.
